# Q-001 — Импорт валидного учебного плана (.plx)

| Поле | Значение |
|------|----------|
| ID | `Q-001` |
| Модуль | Curriculum |
| Приоритет | Must |
| Роль | методист |
| Связанные требования | ФТ-02, ФТ-05 |

## Цель

Импортировать валидный файл `.plx` (MMIS) в каноническую модель и увидеть план в каталоге со статусом «импортирован».

## Предусловия

- [ ] Запущены backend и UI  
- [ ] Вход под ролью методист  
- [ ] Файл из `references/УП_2023/` (валидный `.plx` с BOM UTF-16)  

## Шаги

1. Открыть «Каталог УП» → «Импортировать».  
2. Выбрать валидный `.plx`.  
3. Дождаться завершения импорта.  
4. Открыть карточку плана и проверить дисциплины / часы.  

## Ожидаемый результат

- [ ] Статус импорта: imported (или warning с понятным списком)  
- [ ] В БД есть `curriculum_plans` + строки `plan_disciplines`  
- [ ] Нет необработанного падения процесса  

## Критерии прохождения

- [ ] Время импорта ≤ 60 с для типового файла  
- [ ] Журнал операций содержит запись об импорте
