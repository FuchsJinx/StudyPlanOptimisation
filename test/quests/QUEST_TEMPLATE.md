# Шаблон тестового квеста

Используйте этот шаблон для описания сценария приёмки / регрессии.  
Один квест = одна пользовательская цель с проверяемым результатом.

---

| Поле | Значение |
|------|----------|
| ID | `Q-XXX` |

| Приоритет | Must / Should / Could |
| Роль | методист / диспетчер / администратор |
| Автор | … |
